# Hello, I'm [Philipp](https://github.com/philippsyrov) 👋

I build small, slightly unhinged, genuinely useful software. Agents type, I argue with them.

My work mostly involves local-first apps and AI tooling: native macOS apps, self-hosted AI services, and bots that run on your own models.

## 🚀 My Work

### 📦 Released Projects

Things you can download and run today:

- [Teyvat Virtuoso](https://github.com/philippsyrov/Teyvat-Virtuoso) - A native macOS app that plays MIDI files on the Genshin Impact lyre and piano for you. Built for GeForce NOW.
- [PostPrism](https://github.com/philippsyrov/PostPrism) - A self-hosted GPU service for app builders. One HTTP call turns a social post (text plus up to 10 images or videos) into a search vector, moderation tags, captions and speech transcripts.
- [Sass](https://github.com/philippsyrov/Sass) - A Discord bot that roasts your friends and remembers what they say. Runs on any OpenAI-compatible API or local Ollama.
